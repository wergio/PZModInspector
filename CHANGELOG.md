# Changelog

## 1.0.0 - 2026-10-18

First release: a WPF program `PZModInspector` and the `PZModInspectorCLI` command line to check Project Zomboid mods (Build 42 and
later) without launching the game. It highlights problems with load order, dependencies and version compatibility,
files overwritten by other mods (with diff support), Workshop data from the Steam Web API, and analyzes the errors in
`console.txt`.
